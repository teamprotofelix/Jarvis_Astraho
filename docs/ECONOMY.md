# PR6 자원·연구·건설

자원은 6종, 각각 0~999의 정수다. 원정 결과가 새 mission 번호로 한 번 정산될 때 inventory를 증가시키며 초과분은 999로 제한한다. rewardLedger는 누적 표시/중복 방지이고 inventory는 현재 사용 가능한 재고다. v3→v4 때는 소비 기능이 없었던 기존 원장 counts를 최초 재고로 한 번 복사한다.

## 원자적 거래

순수 applyTransaction은 알려진 recipe/시설과 `tx-N`을 검사하고 복사본에서 비용 차감→작업 등록/출력→로그를 적용한다. 실패하면 원본, 비용, nonce, 로그가 모두 그대로다. 단조 sequence와 최근 64개의 거래 ID를 보존하여 목록에서 지워진 과거 거래도 재실행되지 않는다. 새 ID는 정확히 다음 번호여야 한다. 연구/건설 슬롯은 각각 1개이며 가동 시설 중복 건설은 불가다.

연구는 스쿨드의 고정 작업 시간을 거쳐 설계를 해금하고, 건설은 별도 자원으로 10초 조립 후 level 1이 된다. 중간 남은 시간을 저장하며 재로드로 비용을 다시 내지 않는다. 건축 연출은 점선/투명 시공 오버레이에서 완성 레이어로 바뀐다. 기존 15개 room ID/좌표는 변경하지 않는다.

| 시설 | 기존 방 슬롯 | 실제 효과 |
| --- | --- | --- |
| 탐사 격납고 | workshop | 신호 스캔 1.5×, 탐사 스캔 1.25×, 2B의 격납고 출발 점검 |
| 이변 분석 연구실 | workshop | 후속 연구 시간 0.75×, 표본 분석 제작, 스쿨드의 표본 연구 |
| 생태 온실 | garden | 원정 보급 소모 0.75×, 휴식 회복 +0.4/초, 완다/마리의 온실 손질 |
| 세계수 공명 장치 | garden | 귀환 안정 1.5×, 탐사 스캔 추가 1.25×, 미르의 공명 변화 관측 |

네 시설은 격납고→연구실→온실→공명 장치 순서로 선행 조건이 있다. 첫 수정 해안의 수정 4/별금속 3/기억 2로 격납고 연구와 건설이 가능하다. 세 지역의 표본을 모두 회수하면 네 시설 모두를 마련할 수 있다. 기본 항로·장비·원정 재시도에는 자원이 들지 않아 재고 0에서도 교착되지 않는다.

연구실 가동 후 생태 표본 1 + 고대 파편 1 → 기억 잔향 2 분석 제작을 제공한다. 결과가 재고 상한을 넘으면 비용도 차감하지 않는다. UI 버튼 비활성만으로 막지 않고 모델이 다시 확인한다.

## 상태·생활·아트

Campaign이 mission/expedition/reward/inventory 정산을 함께 소유한다. 효과는 실제 scan/supply/return/research timestep 계산에서 사용한다. 승무원 utility에 설치된 시설 작업을 추가하고, 프로젝트 중에는 스쿨드 연구·조립 작업을 우선한다. 모든 새 작업도 기존 문·복도·shaft를 경유한다. energy는 플레이용 생활 지표이며 세계수·미르·자비스를 동일 존재로 합치지 않는다.

설치 레이어는 Living View/ROOM의 기존 방 슬롯 및 외관 hero에 추가된다. 신규 WebP 35개 후보 중 사용하는 25개만 포함한다: preview 6, scenes 3, layers 3, resource icons 6, fx 3, upgrades 4. 후속 고화질 지역 3·미사용 장비 아이콘 6·보호막 보너스 1은 가져오지 않는다. alpha/frames/hash를 확인하며 선택 캐시로 로드한다. 별도 신규 16번째 방이나 강제 맵 재배치는 없다.

schema4는 inventory/research/construction을 추가하고 v1/v2/v3를 순서대로 검증·확장한다. IDB의 current/before-import, JSON 미리보기/되돌리기/원본 보존을 유지한다. revision/current 서명 충돌 시 stale tab의 저장을 중지한다. 로컬 JSON은 사용자 백업이며 서버 기반 부정행위 방지 수단은 아니다.
