# v1.1 검증 기록

기준: 2026-10-18. 로컬 변경을 검증한 뒤 GitHub main에 반영합니다.

## 자동 확인

- Node 테스트: 기존 회귀 6개 + 신규 상호작용/캐시 14개.
- 225개 출발지·도착지 조합의 직교 이동과 타 모듈 관통 방지.
- 전 승무원의 목적지 도착, 방향 변경, 이동 예약, 잘못된 입력·시간 처리.
- 320/360/390/768/1440 논리 폭에서 비행 경계 유지, 대각선 속도 정규화.
- 별빛 단일 수집, 충돌·무적·보호막 재생, 450초 모델 항해의 9개 구간 순환과 객체 상한.
- 오프라인 설치 목록, 설치 실패 시 새 캐시만 정리, 명시적 업데이트 동의, 같은 출처의 다른 사이트 캐시 보존, 하위 경로 탐색 폴백.
- `npm run check`: 런타임 JS 및 서비스 워커 문법.
- `npm run build`: HTML의 자산과 JS의 DOM ID/상대 import, 51개 WebP 파일의 크기·해시, 64개 오프라인 URL, manifest 상대 경로.
- Pillow 검사: 디코딩·목표 해상도·투명 알파·스프라이트 각 셀의 비어 있지 않은 내용.

## DOM 연결 확인

별도 설치한 LinkeDOM에서 `tests/dom-check.mjs`를 실행하여 12개 통합 그룹을 확인했습니다. 실제 `js/main.js` 모듈을 로드하고 인물 선택·대화·방 열기·활동·이동 예약·일시정지·비행 키보드·모달/창 전환 후 입력 해제·풍경 전환·일지 필터·지도 확대를 실행합니다. DOM 에뮬레이터는 화면을 렌더링하지 않으며, select 기본값·Canvas·포커스·IntersectionObserver는 환경 모사입니다.

## 이미지 최적화

PNG 원본 합계 87,058,532바이트 → 배포 WebP 51개 합계 4,531,672바이트(94.8% 감소). 11개 RGBA 시트와 132개 프레임을 검사했습니다. 원본 PNG는 배포하지 않습니다.

## 미검증

이번 환경에는 지원되는 브라우저 제어 기능이 없어 실제 브라우저를 시작하지 않았습니다. 다음은 별도 확인 대상입니다.

- PC/모바일 실제 레이아웃·오버플로·이미지 로딩과 애니메이션.
- 키보드 포커스 트랩·복원, 지도 따라가기, 실제 터치·포인터 캡처.
- 실제 150초 브라우저 항해와 창 전환·스크롤·대화창 열기 후 입력 해제.
- 실제 서비스 워커 A→B 업데이트, 사용자 동의 이후 갱신, 오프라인 재방문.
- Android 홈 화면 설치, iOS/Safari, 저사양 기기 성능.

모델/VM 테스트 결과를 브라우저나 실기기 검사 결과로 해석하지 않습니다. 동적 진행과 수집 수치는 메모리에만 유지됩니다.
