# PWA identity and runtime quality (PR8 / v1.9.0)

The delivery's five PNGs are copied byte for byte. `assets/pwa-art-manifest.json` pins SHA-256, byte count and decoded dimensions. The 1024 master is a design source and is not deployed. The manifest keeps relative `start_url`, scope and icon paths; 192/512 use `any`, the dedicated 512 uses `maskable`. HTML uses the 64 favicon and 180 Apple icon. HTML theme, manifest theme/background all use `#0b172a`.

The main artwork and tree emblem remain visible in simulated round and rounded-square crops. [Contact sheet](qa/pr8/icon-previews.webp) includes a centered 80% safe circle. These are generated mask previews, not Android/iOS installation screenshots. Existing launchers can keep their own OS cache; there is no promise that a website refresh replaces a physical launcher icon immediately.

The scope-specific `v1.9.0` shell atomically precaches 97 URLs, including five PNGs (567,206 bytes). Story full scenes, thumbnails and symbols remain optional request caches. A failed install discards only its new cache; activation keeps sibling-site caches and optional art. No cache operation deletes IndexedDB. The update toast waits for the user's acceptance, flushes current progress, requests skip-waiting and reloads after controller change. The actual v1.8.0→v1.9.0 browser test and subsequent offline revisit are recorded in [QA](qa/QA_PR8.md).

The app cancels its animation callback while paused, unfocused, hidden or inside a dialog. Resuming starts one callback and resets the time origin; hidden time is not replayed. A global pause button is available on every view. Selected map/living panels update when visible; unchanged feed/status HTML is reused. Mission distance uses a scalar getter instead of cloning the whole flight snapshot per frame. Canvas DPR remains capped at 2. Reduced-motion changes are observed at runtime.

Ordinary saves compare full snapshots excluding `savedAt`. Unchanged paused snapshots do not make repeated IndexedDB writes. Import backup and explicit restore always write. A successful write alone updates the fingerprint; quota failures can retry and stale-tab conflicts still stop saving. Schema remains 5, with `current` and `before-import` retained. Future/corrupt records are preserved; JSON export remains available if storage fails.

`npm test`, `npm run check`, `npm run build` cover the runtime and exact PNG/manifest contract. Optional `tests/quality-browser.py` covers real browser layout, failures, AX/focus and frame cancellation. `tests/story-tabs-browser.py` and `tests/story-import-browser.py` exercise actual storage conflicts and undo. `tests/pwa-update-browser.py` starts its own local server and tests the historical PR7 commit through the new update; no production endpoint is modified. `tests/perf-browser.py` uses 1,200 seconds of wall time, CDP heap/task counters and a bounded frame sampler without a virtual clock. It reports headless Chromium, not mobile GPU, power or thermal behavior. Workload, instrumentation and limits must accompany any performance interpretation.

Rollback: export schema-5 JSON first and keep IndexedDB intact. Reverting to pre-PR7 code can reject schema 5; restore the backup only in compatible code. Reverting PR8 alone retains the story schema. Do not clear site data as an update remedy.
