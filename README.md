# ASTRAHO WORLD — The Living Ark

정적 웹사이트 형태로 구현한 아스트라호 생활 관측 시뮬레이션입니다. **실제 우주선/현실 세계/AI 서비스의 실시간 측정값이 아닙니다.** 2026-09-21 통합 백과의 최신 정전과 2026-09-16 프로젝트 지침을 기준으로 공개 가능한 창작 장면만 담았습니다.

## 구현 현황

- 15개 클릭 가능한 모듈과 각 모듈의 개별 제작 SVG 일러스트 15개.
- 11명(에온/E, 서아, 미르, 울드, 스쿨드, 2B, 마리, 요르, 아멜리아, 완다, 세레나)의 각기 다른 6-frame SVG 스프라이트, 모듈 간 복도 경유 이동과 개별 체류 시간, 활동 조회.
- 9개 항해 구간, 다층 별빛/성운/행성/게이트/오로라/블랙홀 효과, 1개의 통일된 방주 항해 SVG, AUTO/MANUAL 조종 (방향키, WASD, 터치).
- 새로 창작한 자비스 가상 항해일지 12개, 구역 필터, 세부 기록.
- GitHub Pages 서브경로 지원, 설치 가능한 PWA, 정적 자산 오프라인 캐시, 업데이트 확인 후 수동 적용.

## 시작

```sh
python -m http.server 8000
# http://localhost:8000
npm test
npm run check
npm run build
```

모든 이미지 자산은 자체 생성한 SVG와 PNG입니다. 외부 라이브러리/서버 API/개인정보 저장/로그인/쿠키/추적 서비스가 없습니다. 기본 CSS는 네트워크 폰트가 없어도 시스템 폰트로 동작합니다.

## GitHub Pages

저장소 Settings → Pages → **Build and deployment: Deploy from a branch** → Branch **main** → Folder **/(root)** → Save. 이후 `https://teamprotofelix.github.io/Jarvis_Astraho/` 경로에서 서비스할 수 있습니다. GitHub API를 통해 Pages 활성화 권한이 없어도 소스는 `main`에 남습니다. 아직 확정되지 않은 사용자 도메인을 CNAME에 기록하지 않습니다.

## 수정 포인트

- `js/world-data.js`: 공식 모듈, 승무원, 시뮬레이션용 활동, 항해 풍경, 자비스 아카이브를 관리합니다. 여기의 항해일지는 기존 개인 대화 원문이 아닌 공개용 오리지널 짧은 창작입니다.
- `js/simulation.js`: 구성원별 경로/속도/대기/가상 좌표 계산.
- `js/flight.js`: canvas 풍경, AUTO/MANUAL 및 입력.
- `js/main.js`: 내비게이션, 지도, 상세 모달, PWA 사용자 업데이트 절차.
- `assets/scenes/*.svg`: 15개 구역 장면; `assets/sprites/*.svg`: 11개 캐릭터 시트(6 frames); `assets/ship-map.svg` 및 `ship-side.svg`: 같은 디자인 계열의 지도 및 항해 함선.
- `sw.js`: 새 버전에서 `VERSION`을 변경하고 캐시 목록에 신규 리소스를 추가합니다. 서비스 워커는 기존 화면을 강제 새로고침하지 않습니다.

## 정전과 창작의 경계

- 자비스 = 중앙 시스템/기록관. 아스트라호의 살아있는 영혼이나 부함장은 아닙니다.
- 서아 = Executive Vice Captain, 인적 지휘·항로·외교. E = 방향과 가치의 최종 선택. 미르 = 공동 주인/근원 수호자. 에이온 위그드라실 = 독립된 살아있는 세계수.
- 에아는 자유로운 유랑자, 실라는 별도 공동체를 책임지는 독립 통치자로 표시하기 위해 현재 상주 지도에는 포함하지 않았습니다.
- 영원의 수련실의 설정상 시간 비율, 차원 신호, 상태판 값은 허구입니다.
- **PROVISIONAL**: 15개 방의 정사각 격자 배치, 각 인물의 분 단위 이동 경로·휴식 시간, 항해력 001~012 일지 날짜·사건·대사 및 항해 시각은 이 사이트의 시각화를 위해 새로 창작한 비정전 요소입니다. 과거 사건의 사실처럼 재사용하지 마세요.
- 기존 원문에 있는 사적인 대화·선물·일기 전체를 공개 저장소에 게시하지 않았습니다. 공개 전용 텍스트만 포함합니다.

## 검증 및 한계

`npm test`, `npm run check`, `npm run build`와 Playwright/Chromium PC·모바일 동작 검증을 권장합니다. 실제 Android/iOS 설치, 기기별 홈 화면 동작, 실제 GitHub Pages 배포 설정은 환경에 따라 별도 검증해야 합니다. CSS/SVG 기반 제작물이므로 생성형 이미지 모델로 제작한 고해상도 래스터 아트는 포함하지 않았습니다. 첫 버전 이후 변경은 브랜치 → PR → 검토 → main 병합으로 관리하세요.
