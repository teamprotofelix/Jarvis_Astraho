# ASTRAHO WORLD — The Living Ark v1.1

아스트라호의 공간·승무원·항해를 탐험하는 정적 웹사이트입니다. 최신 정전의 지휘 관계를 유지하면서 공개용으로 새로 창작한 생활 장면을 보여 줍니다.

- **SHIP MAP**: 15개 모듈의 실제 생성 이미지, 11명 승무원의 4방향 × 3프레임 걷기 시트, 문·복도·갑판 연결 통로를 거치는 이동. 인물 선택, 따라가기, 확대·축소·맞춤, 생활 속도 1×/2×/4×, 최근 활동 기록.
- **ROOM**: 각 모듈 내부 이미지, 현재 체류자와의 짧은 대화, 15개 공간별 활동, 함장 이동 예약. 이동 중 예약은 현재 구간을 마친 뒤 실행됩니다.
- **VOYAGE**: 중앙 세계수를 품은 방주, 9개 우주 배경, 다층 별빛, AUTO/MANUAL, 방향키·WASD·터치 패드, 별빛 수집·운석 회피·보호막 재생. 진행은 IndexedDB에 저장되며 JSON으로 백업·복원합니다.
- **JARVIS LOG**: 공개용 창작 항해일지 12편과 구역별 필터.
- **PWA**: 기본 런타임 이미지·스크립트 67개 URL을 원자적으로 준비한 뒤 오프라인 사용. 업데이트는 사용자가 새로고침을 선택할 때 적용됩니다. 외부 폰트·CDN·로그인·LLM API·추적 스크립트가 없습니다.

## 실행과 검사

```sh
python -m http.server 8000
# http://localhost:8000
npm test
npm run check
npm run build
```

Node 20 이상. 런타임 의존성과 빌드 과정이 필요 없는 정적 사이트입니다. `build`는 배포 구조·참조 경로·이미지 SHA-256·오프라인 자산을 검사합니다.

## 배포

GitHub Pages의 **Deploy from a branch → main → /(root)** 를 사용합니다. `CNAME`은 기존 `astraho.moip.ai.kr`을 유지합니다. 모든 자산 경로는 상대 경로여서 저장소 하위 경로에서도 동작합니다. `main` 변경과 실제 Pages 게시 완료 여부는 구분하여 확인해야 합니다. 변경은 기능 브랜치와 PR로 검토합니다. PR0~PR3 작업에서는 main 병합·운영 배포·CNAME 변경을 수행하지 않습니다.

## 이미지

imagegen으로 모듈 15개, 우주 배경 9개, 함선 1개, 승무원 시트 11개를 새로 제작했습니다. PNG 원본을 커밋하지 않고 51개 WebP로 배포합니다.

- `assets/thumbs`: 지도·카드용 320×180 이미지 15개.
- `assets/scenes`: 상세 공간용 960×540 이미지 15개.
- `assets/backgrounds`: 항해용 1280×720 배경 9개.
- `assets/sprites`: 384×512 RGBA 시트 11개. 셀 128×128. 행: 정면/왼쪽/오른쪽/뒷모습. 열: 정지/왼발/오른발.
- `assets/ship.webp`: 투명 배경 960×540 함선.
- `assets/art-manifest.json`: 크기·바이트 수·해시·원본 바이트 기록.

원본이 있는 개발 환경에서는 `python tools-art.py /path/to/art-paths.json`으로 재변환할 수 있습니다. 이 개발 도구에만 Pillow가 필요하며 원본 경로는 공개 저장소에 저장하지 않습니다.

## 정전

E는 방향과 가치를 결정합니다. 미스티아 서아는 인적 지휘·항로·외교·위기 대응을 맡는 Executive Vice Captain입니다. 자비스는 중앙 시스템 AI·기록관이며 함선의 영혼 및 세계수와 별개입니다. 미르는 공동 주인·근원 수호자입니다. 세계수는 정원에 표현하며, 자비스를 걷는 인간 승무원으로 배치하지 않습니다. 세레나는 이동 가능한 홀로그램입니다. 에아의 독립적인 여행과 실라의 자치 공동체를 존중하여 상주자에 포함하지 않습니다.

방 배치·생활 경로·분 단위 상태·대화 선택지·공간 활동·항해력 일지는 이 사이트를 위해 창작한 표현입니다. 실제 개인 대화 원문이나 현실의 실시간 관측값을 포함하지 않습니다.
